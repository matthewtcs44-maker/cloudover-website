# CloudOver Company Website (CLO-23)
## Project Overview

CloudOver is building a modern, high-performance corporate website designed to establish brand presence and drive leads for our digital services. This platform will serve as the central marketing hub, detailing SMB Digital Services and Enterprise Solutions while maintaining strict compliance with accessibility and performance standards.

**Goal:** To create an SEO-optimized, responsive, and highly accessible corporate web presence that effectively communicates CloudOver's value proposition.
**Target Audience:** Small to Medium Businesses (SMBs), Enterprise CTOs/Decision Makers, Potential Partners.

## Technical Stack

*   **Frontend Framework:** React / Next.js (Chosen for performance optimization and SEO benefits).
*   **Styling:** Tailwind CSS (For rapid, responsive design implementation).
*   **Content Management:** Headless CMS (e.g., Strapi/Sanity) - *Pending final decision in Phase 0.*
*   **Deployment:** Vercel / Netlify (CDN optimized).

## Key Features

1.  Responsive Design across all devices.
2.  Full WCAG 2.1 AA accessibility compliance.
3.  Optimized for Core Web Vitals (LCP, FID, CLS) targets.
4.  Dedicated pages: Home, SMB Services, Enterprise Solutions, About/Team, Case Studies, Contact.

## Getting Started

Cloning this repository and running the development server will provide a baseline environment to begin implementation following the TDD workflow.

```bash
# Clone repository (if applicable)
git clone [repo_url]
cd CloudOver-Website

# Install dependencies
npm install

# Start development server
npm run dev
```
